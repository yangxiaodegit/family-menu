# 家庭点菜 V8.1 无感主机版

## 变化
- 不再显示“家庭主机”页面
- 不需要手动启动主机
- 页面打开后自动：
  1. 尝试连接已有家庭主机
  2. 如果没有主机，则当前设备自动成为主机
- 用户只看到“已连接 / 正在连接 / 离线可用”
- 主机连接数、广播、同步、自动重连等技术细节全部隐藏
- 页面切回前台、网络恢复时自动重连
- 实时数据、历史、库存、设置仍然由自动主机设备本地保存

## 使用
所有家人只需打开同一个固定链接。
无需理解主机、数据库或同步机制。

## GitHub Pages
菜品数据已拆分为多个小文件，以兼容 GitHub 发布通道；功能与 V8.1 部署包一致。
